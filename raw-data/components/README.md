# components

Our own choices for Character Structure component cards. Nothing here comes
from outside sources.

## `ours.json` — component overrides

Applied **last** when `scripts/generate-v2-json.mjs` builds
`public/json/v2/components.json`, so an entry here always wins. Use it to
fill a missing keyword or correct a wrong one.

```jsonc
{
  "𠂊": { "k": "katakana ku" }, // fill a gap
  "龶": { "k": "the blue crown" }, // replace a keyword from another source
}
```

Fields (all optional, same shape as a generated entry):

- `k` — keyword shown on the component card
- `s` — phonetic sounds, e.g. `["ちょう", "かん"]`
- `n` — stroke count

`docs/data/component-coverage.json` is regenerated by `pnpm run generate-json`
and lists every component still missing a keyword, most-referenced first —
that is the worklist for this file.
